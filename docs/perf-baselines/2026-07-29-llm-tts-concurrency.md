## 观察

- 1～3 路并发可用，未见业务失败。
- 并发上升后，TTS 首音频从单路约 1.1s 上升到 3～5 路的约 1.4～2.2s。
- 5 路第二轮服务端全部完成，但客户端脚本第一轮有误判，需要改进测试器后复测。
- 日志中出现 `生成并保存聊天标题失败: Agent not found`，这是管理端会话标题保存问题，不影响主链路，但会污染日志，后续应单独处理。
- 日志中出现 `get_weather` 鉴权失败，说明 prompt 动态上下文尝试取天气但 key 不可用。该错误不阻断主链路，但会增加噪声。

## 初步结论

当前 LLM + 火山双流 TTS：

- 3 路并发可认为稳定。
- 5 路并发服务端可跑完，但需要改测试器后确认客户端侧稳定性。
- 火山双流 TTS 在 3～5 路下首音频会升到约 1.5～2.2s，后续要关注火山侧连接复用和并发配额。
